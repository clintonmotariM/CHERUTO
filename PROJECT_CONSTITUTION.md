# PROJECT CONSTITUTION

This document is the absolute law for this project.

## 1. Mobile-First

- All touch targets must be at least `44px` by `44px`.
- The base font size must be `16px`.
- Horizontal scrolling is prohibited.

## 2. The Exit Code

- A `44x44px` Exit button must always exist in the top-right corner.
- It must respect safe-area positioning: `top: max(env(safe-area-inset-top), 16px)` and `right: 16px`.

## 3. Lively Color Palette — Cherono's Palette

- Background: `#FFF9F2` (Warm bright cream)
- Text: `#5D4037` (Rich warm brown)
- All buttons: `#FF4D85` (Vibrant Pink) with white text
- Accent purple: `#9D4EDD` (Bright Purple)
- Accent green: `#2ECC71` (Vivid Green)

## 4. Asset Constraint

- Do not use default blue links or browser styling.
- Every interactive control, link, icon, surface, and text treatment must follow Cherono's Palette.
